# Group presentation slides

For the group presentation slides, agree on the audience, main message, and who owns each section. Create a shared outline before designing slides. Use one main idea per slide, readable charts, and short supporting text.

Leave time to rehearse the group presentation aloud. Check the speaking time, transitions between presenters, and consistency of slide formatting. Add sources for charts and borrowed facts. Finish with a slide that states the recommendation and its supporting evidence.
