# Statistics problem set

For the statistics problem set, practice confidence intervals and hypothesis tests. Start by identifying the sample mean, sample standard deviation, and sample size. Check the independence and distribution assumptions before choosing a formula.

When solving hypothesis tests, write the null and alternative hypotheses, choose the significance level, calculate a test statistic, and interpret the p-value in context. Finish by explaining the conclusion in plain language. A confidence interval describes uncertainty around an estimate; it is not a range containing a fixed percentage of individual observations.
