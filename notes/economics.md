# Economics reading

For the economics reading, review supply, demand, equilibrium, and price elasticity. Sketch the supply and demand curves, identify which curve shifts in each example, and explain the effect on equilibrium price and quantity.

After each economics section, close the book and summarize the main idea from memory. Compare elastic and inelastic demand using examples, then attempt the end-of-chapter questions. Record unfamiliar terms so they can be reviewed before the next class.
